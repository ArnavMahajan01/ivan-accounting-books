Summary

OptionApproachEase and safety
1: Safe SheetCounts, balance check and lines in a sheet over the Bank page★★★★☆
2: Step FlowChoose, check, done, one step at a time★★★☆☆
3: Full PageA full-page table with filters, for big files★★★☆☆
4: Inline RowDrop a file on its account, preview inside the row★★★☆☆
5: Plain SummaryThe same sheet, written as sentences, with the table one click away★★★★★

Recommended: Option 5, Plain Summary. It keeps Option 1's sheet over the Bank page, but says what will happen in plain words, so a duplicate or a bad line is understood without reading a table. The filters from Option 3 can be added inside "See all lines" for big files.

Use "Show" above each window to switch between a clean file, a file with duplicates, and a file with a bad line and a balance warning. All data is invented.
