# Demo Feedback

What the client says at each demo (the last spec of each `NN-demo-N-...` folder). The author fills it in on the day. Wireframe feedback before any code is in `wireframe-feedback.md`.

**Rules:**

- Every row says who said it and the date: "client, 2027-01-15".
- Write what he wants, not how to build it.
- No real figures, names or account numbers, even if he used his own file at Demo 3.
- Each change becomes a new spec with a letter suffix (in that folder or a later one), listed in `feature-specs/README.md`. Write the spec number in the last column.
