# 100: Customise a Report: Columns and Rows

The side panel that changes a report's columns and rows live (W06a, Option 2).

**Client sees:** ticking "Last quarter" adds the column straight away.

## Depends On

- 099

## Implementation

1. Columns: this period, last period, same period last year, % of income, month by month.
2. Rows: show empty accounts, group small expenses as "Other", show codes.
3. Ready layouts to start from (W06a, Option 5): Compare quarters, Month by month, For the accountant.

## Check When Done

- Each column's figures are tested. The figures still come from the books. Impeccable `critique`.
