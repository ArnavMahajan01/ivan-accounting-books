# W04: Wireframe: Bank Page and Import Preview

Wireframes for bringing in a Westpac statement file: the Bank page and the import preview. This is the first real job the client does in the app.

## Depends On

- W03

## Implementation

1. Run `/wireframe` for "the Bank page and importing a Westpac statement file with a preview", choosing Wireframes only. Use the shell layout the author preferred in W03 as the starting point for the safe option.

2. Make sure the options cover the flow from `project-overview.md` ("Core User Flow", steps 1 to 3): drag a file or click **Import file**, see the preview with counts of new, duplicate and rejected lines, see the closing balance check pass or warn, then **Import** or **Cancel**.

3. Check the options show three states: a clean file, a file with duplicates, and a file with a rejected row and a balance warning.

4. Record the option names and the recommendation in the progress file.

## Scope Limits

- No categorising. W05.
- No Westpac Online Banking screens.

## Check When Done

- The wireframe opens and every tab works.
- The three states in step 3 can each be seen in at least the recommended option.
- Invented data only.
