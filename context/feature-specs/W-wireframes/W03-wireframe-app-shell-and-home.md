# W03: Wireframe: App Shell and Home

The first wireframe: the window, the sidebar, and the Home page. Every other screen sits inside this shell, so it is agreed first.

## Depends On

- W02

## Implementation

1. Run `/wireframe` for "the app window with its sidebar, and the Home page", choosing Wireframes only. Feed it the Home and Layout sections of `ui-context.md`: the sidebar items, the four summary numbers, the warnings, recent imports and the next BAS date.

2. Check each of the 5 options shows the sidebar sections from `ui-context.md`, the Home summary numbers with invented AUD amounts, and an empty state for a brand-new book ("No bank lines yet").

3. Write a short note in the progress file: the 5 option names, the recommended one, and one line on how each differs.

## Scope Limits

- Only the shell and Home. No other page content.
- No colour variants unless the author asks.

## Check When Done

- `wireframe/<DDMM>-app-shell-and-home/index.html` opens in a browser, and every tab and sub-tab works.
- Each option shows invented data only, Australian date format and AUD.
- The author has clicked through all 5 options.
