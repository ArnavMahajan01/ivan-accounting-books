# 113: Ready Formulas Tab

A tab in every workbook, and a list in the app, of plain-English formulas he can copy (W07a, Option 4).

**Client sees:** Ready formulas with Copy buttons.

## Depends On

- 112

## Decide First

- Client question 22 (which calculations he does today). Start with the list in W07a.

## Implementation

1. The formulas as data: name, what it does, the formula, an example. GST in an amount uses `ROUND(x/11, 2)`, never 10%.
2. Written to the Ready formulas tab (RAW text for explanations, formulas only in the example cells), and shown in the app with Copy.

## Check When Done

- Each formula gives the expected result in a test sheet (manual check, recorded).
