# Wireframe Sign-Off

**Status:** Decided: the recommended option for every screen

Which wireframe option each screen is built from. It decides the layout of every screen from spec 020 on. It does not decide colours or type (spec 020) or anything the client asks for later, which becomes new specs.

## The Options

For each of the 13 screens in `wireframe/`, five black-and-white options (W03 to W09a, W05a, W05b, W08a, W08b), with a recommended option or combination in `wireframe-feedback.md`.

## Comparison

The options and the reasons for each recommendation are in `wireframe-feedback.md`, beside each screen, and in each wireframe's notes.

## Why The Choice Matters

It sets the shape of every screen and the order work is shown in. Layouts can still change after a demo, as new specs, without touching the ledger or the data underneath.

## Recommendation

The recommended option for each screen, as listed in `wireframe-feedback.md`.

1. The client reviewed the wireframes (W10). Reported by the author on 2026-11-22.
